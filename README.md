# Exide Product Search System

A dynamic battery product search application built using HTML, CSS, JavaScript, and Python.

## Features

- Product Code Search
- Voice Search Support
- Related Product Suggestions
- Complete Category-wise Product Listing
- Excel to JSON Automation
- GitHub Pages Ready
- Mobile Responsive

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- JSON

## Project Structure

/product-search
│
├── index.html
├── products.html
├── products.json
├── style.css
├── app.js
├── update_products.py
└── README.md

## Workflow

1. Update Excel Product List
2. Run Python Script
3. JSON File Gets Updated
4. Website Reflects New Data Automatically

## Voice Search

Users can search products using voice input.

Example:

E P I Q 3 5 L
